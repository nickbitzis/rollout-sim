Automated analysis

At the end of each bake, a one-sided two-proportion z-test compares v2 errors with v1. It fails if the result is significant and v2 is at least 0.5 points worse. The p99 check fails if v2 is confidently more than the tolerance slower.

Each minute, requests are split between versions, and errors and p99 are sampled from each version's true rates. Runs are reproducible from the seed.
